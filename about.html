About Travel Planner 🌍

A simple and useful travel companion designed to make planning journeys easier, smarter and more organized.

Our Features

☀️ Weather Forecast

View current conditions and a seven-day forecast for destinations.

💱 Currency Converter

Convert currencies using available exchange-rate information.

🗺️ Maps and Routes

Explore city locations and find estimated driving routes.

💰 Budget Manager

Estimate trip costs and record travel expenses.

🗓️ Itinerary Planner

Organize destinations, dates and planned activities.

🎒 Packing Checklist

Track essential items before starting your journey.

Technologies Used

HTML5 · CSS3 · JavaScript · Open-Meteo API · Frankfurter API · Leaflet.js · Esri Maps · OSRM · Browser Local Storage

Project Purpose

Travel Planner is a front-end web application developed to bring common trip-planning tools together in one convenient interface.
